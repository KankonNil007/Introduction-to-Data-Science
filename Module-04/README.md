## 📌 Overview

This final module bridges the gap between data manipulation and statistical analysis. It introduces basic statistical concepts, distributions, and hypothesis testing, demonstrating how to apply them using the `scipy` library alongside `pandas`.

## 🎯 Learning Objectives
- Understand fundamental statistical distributions and their real-world applications.
- Formulate null and alternative hypotheses for data testing.
- Conduct statistical significance tests (like the t-test) to compare different data samples.
- Interpret p-values to make scientifically sound conclusions from datasets.
- Clean and manipulate messy, real-world data specifically for statistical querying.
