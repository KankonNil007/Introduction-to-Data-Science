## 📌 Overview

This module introduces the basics of the Python programming environment and the fundamental data structures and techniques used for data manipulation and analysis, laying the groundwork for more advanced libraries like Pandas.

## 🎯 Learning Objectives
- Master fundamental Python programming techniques such as lambdas and list comprehensions.
- Understand how to read, write, and manipulate CSV files using core Python structures.
- Grasp the basics of the **NumPy** library for fast, scientific computing and array manipulation.
- Utilize Regular Expressions (Regex) for advanced pattern matching and text extraction.
