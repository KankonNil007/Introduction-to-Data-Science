## 📌 Overview

This module dives deep into Python's premier tool for data analysis: `pandas`. It focuses heavily on understanding and utilizing the `Series` and `DataFrame` abstractions to manipulate tabular data efficiently.

## 🎯 Learning Objectives
- Instantiate and query the `Series` 1-dimensional labeled array data structure.
- Construct and index structured data using the 2-dimensional `DataFrame`.
- Practice vectorization to perform lightning-fast math operations across massive datasets in Pandas.
- Implement data cleaning techniques, specifically handling missing datasets (`NaN` values).
- Add, drop, and modify DataFrame rows and columns effectively.
